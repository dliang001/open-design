# Memphis 80s

> Ettore Sottsass's Memphis Group, recovered for the screen. Big shapes,
> playful clashing colours, deliberate "wrongness" that reads as confident
> rather than naive. Use for kids' brands, cultural events, food packaging,
> creative agencies.

## Visual Theme & Atmosphere
Geometric chaos held together by typography discipline. Squiggle / triangle /
dot patterns punch through layouts. Background is always warm cream, never
white.

## Color Palette & Roles
- **Background:** `#F8F4E8` (cream)
- **Foreground:** `#0E0E0E` (true black) — body text and bold blocks
- **Primary accent:** `#F2541F` (signal orange)
- **Secondary accent:** `#1554B5` (cobalt blue)
- **Tertiary accent:** `#F4C430` (mustard yellow)
- **Quaternary accent:** `#FF6BA6` (hot pink)
- **Surface 2:** `#0E0E0E` (used as a colour block, NOT as page background)

Multiple accents are intentionally combined. There is no "ONE accent only" rule here.

## Typography
- **Display:** "Druk", "Acumin", or any heavy condensed sans at 800–900 weight; tracking tight (-2%)
- **Body:** "Inter", "Univers", or "Helvetica" at 16–18px
- **Decorative:** a script / handwritten font appears in ONE callout per screen

## Component Stylings
- **Buttons:** solid colour fill (any of the 4 accents), 0–4px radius, no shadow. Hover swaps to a different palette accent.
- **Cards:** flat colour blocks; the card's fill IS the visual.
- **Patterns:** squiggle / dot / zigzag SVG borders on section dividers.
- **Imagery:** photos drop into rounded rectangles offset from a coloured block behind ("paper sticker" effect).

## Layout Principles
- Compositions are off-grid: blocks of colour overlap, nest, and sit at slight angles (3–6°).
- Each screen has 2–3 "shape moments" (a rotated block, a squiggle line, a dot pattern).
- Outer margins are loose (96px on desktop) so shapes can bleed off-page.

## Depth & Elevation
Flat colour, no shadows. Depth is implied through layered rectangles offset by 4–8px (paper-stack effect).

## Do's and Don'ts
- **Do** use 3+ palette colours on the same screen.
- **Do** rotate decorative blocks 3–6° (never more — that reads as broken).
- **Do** add SVG squiggle / dot / chevron patterns as section dividers.
- **Don't** use white as a background.
- **Don't** use shadows or gradients.
- **Don't** use thin type — display always heavy.

## Responsive Behavior
Decorative shapes scale down and clip to viewport edge on mobile. Type stays bold.

## Agent Prompt Guide
1. Use cream background, never white.
2. Combine 3 of the 4 accents on every screen.
3. Add 1–2 decorative SVG patterns per page (squiggle, dots, chevrons).
4. Rotate one or two blocks 3–6°.
5. Type is always heavy condensed; never light or extralight.
